# Data Model: Переключатель порций (UI)

Модель фронтенда: что UI получает из API (типы в `frontend/src/api.ts`) и что держит сам. Источник полей — раздел «Что я гарантирую UI» в `specs/002-servings-logic/spec.md`; подмножество, на которое опирается UI, — [contracts/api-consumed.md](contracts/api-consumed.md).

## Из API

### Multiplier

`1 | 2 | 4`. Других значений UI не показывает.

### Variant (новое)

| поле | тип | правило для UI |
|---|---|---|
| `multiplier` | `Multiplier` | ровно по одному варианту на 1, 2, 4 |
| `total_price` | целое, ₽ | итог карточки при этом множителе; не пересчитывается |
| `quantities` | `Record<string, number>` | ключ — `String(xml_id)`; значение должно быть у каждого товара подборки |
| `cart_url` | строка | всегда есть; ссылка основной кнопки |
| `available` | boolean | `false` → сегмент неактивен |
| `reason` | строка, необязательно | показывается только при `available: false` |

### Product (расширение)

| поле | тип | правило для UI |
|---|---|---|
| `scalable` | boolean, необязательно | `true` → при ×2/×4 показывать «было»; нет поля — как до фичи |
| `base_quantity` | number, необязательно | количество ×1 для «было» |
| остальные | как сейчас | — |

### Collection (расширение)

| поле | тип | правило для UI |
|---|---|---|
| `variants` | `Variant[]`, необязательно | имя закреплено командой 2 (research R-6); нет или не проходит проверку R-4 → карточка без переключателя |
| `servings` | `Multiplier`, необязательно | UI не читает: в поиск `servings` не передаётся, применённый множитель всегда 1 |
| `total_price`, `cart_url`, `products` | как сейчас | совпадают с вариантом ×1; используются, когда вариантов нет |

### ApiError (новое, значение ошибки)

| поле | тип | откуда |
|---|---|---|
| `status` | number | HTTP-код ответа |
| `code` | string, необязательно | поле `code` тела ошибки; нет или тело не JSON — `undefined` |

## Состояние страницы

### ServingsSelection

`Record<collectionId, Multiplier>` в `App`. Ключа нет → ×1.

- Создаётся пустым при загрузке страницы.
- Меняется только выбором в переключателе карточки.
- Не сбрасывается при смене запроса и фильтров; записи ушедших из выдачи подборок остаются (FR-011).
- Не пишется в адрес и `localStorage`; после перезагрузки пусто.

### Производное: CardView (вычисляется при отрисовке)

| значение | как получить |
|---|---|
| `variants` | `readVariants(c)` → `Variant[] \| null` |
| `active` | вариант с `multiplier = selection[c.id] ?? 1`. Если он `available: false` (стал недоступен после обновления) — ×1 |
| `total` | `active.total_price`, без вариантов — `c.total_price` |
| `cartUrl` | `active.cart_url`, без вариантов — `c.cart_url` |
| `cartLabel` | ×1 — «Перенести в корзину ВкусВилла»; ×2/×4 — «Перенести в корзину ВкусВилла · ×N» |
| строка состава | количество `active.quantities[xml_id]`; «было `base_quantity`» — только при `multiplier > 1` и `scalable === true` |
| `overBudget` | `maxPrice > 0 && total > maxPrice` |

## Переходы выбора

```text
          выбор ×2                выбор ×4
  ×1 ────────────────▶ ×2 ────────────────▶ ×4
   ▲                    │                    │
   └──── выбор ×1 ──────┴──── выбор ×1 ──────┘
  (любой выбор доступного сегмента; недоступный не выбирается)

перезагрузка страницы  → все ×1
подборка ушла/вернулась → прежний выбор
варианты пропали в новом ответе → карточка без переключателя; выбор в словаре остаётся
```
