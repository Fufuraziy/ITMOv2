# Contract: карточка подборки (доступная структура)

Роли, доступные имена и тексты, на которые опираются тесты (`App.test.tsx`) и программы чтения с экрана. Визуальное оформление — через skill frontend-design, здесь не фиксируется.

## Страница

| состояние | элемент | роль / имя |
|---|---|---|
| первая загрузка | строка в `main` | текст «Ищем подборки…» |
| пусто / ошибка | как сейчас | без изменений |

## Карточка с вариантами

| элемент | роль | доступное имя / текст |
|---|---|---|
| карточка | `article` | название подборки (как сейчас) |
| переключатель | `group` (`fieldset`) | «Порции» |
| сегменты | `radio` ×3 | «×1», «×2», «×4»; ровно один `checked`; по умолчанию «×1» |
| недоступный сегмент | `radio`, `disabled` | имя «×N»; описание (`aria-describedby`) — `reason` из ответа |
| итог | текст, `aria-live="polite"`, `aria-atomic="true"` | ×1: «≈ 1 111 ₽»; ×N: «≈ 1 417 ₽ · ×2» |
| пометка бюджета | текст рядом с итогом | «больше бюджета» — только когда итог выбранного варианта > выбранного бюджета |
| кнопка корзины | `link`, `target="_blank"`, `rel="noopener noreferrer"` | ×1: «Перенести в корзину ВкусВилла»; ×N: «Перенести в корзину ВкусВилла · ×N»; `href` — `cart_url` выбранного варианта |
| состав | `button` «Состав: N товаров» + `list` «Состав подборки «…»» | как сейчас |
| строка состава, масштабируемый, ×N | `listitem` | «2 шт · было 1 шт × 306 ₽» — количество ×N, «было» с `base_quantity` |
| строка состава, немасштабируемый или ×1 | `listitem` | «1 шт × 306 ₽» — как сейчас |

Клавиатура: Tab переводит фокус в группу, стрелки меняют выбор (нативное поведение radio).

## Карточка без вариантов

Нет `group` «Порции»; итог, кнопка и состав — как до фичи (FR-010).

## Инварианты для тестов

- Выбор в одной карточке не меняет `checked` в других (FR-002).
- Смена выбора не увеличивает число вызовов `fetch` (FR-003, SC-001).
- Адрес страницы не меняется при смене выбора (FR-002, FR-011).
- В запросах `/collections` нет параметра `servings` (FR-018).
- У ×2/×4 `href` кнопки — `cart_url` именно этого варианта (SC-002).
