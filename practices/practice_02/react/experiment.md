# ReAct Experiment

Role: Lead QA / Tech Lead

Цикл ReAct (мысль → действие → результат):

Мысль:
- В исходнике отсутствуют: явный N, согласованные SLO, методика и решение о запуске нагрузочного тестирования. Это делает артефакт непригодным для воспроизводимых проверок.

Действие:
- Зафиксировали N=20000 (CASE.md API-1) и цели p95 ≤ 3s, 5xx ≤ 1% (problem.md).
- Добавили методику k6 и thresholds на http_req_duration p(95)<3000 и http_req_failed rate<0.01.
- Дополнили таблицу сценариев и оформили блок «Решение о запуске» с условиями старта.

Результат:
- Сформирован practices/practice_02/react/tests_load.md: полная версия с правилами, методикой, сценариями и условиями запуска.

Что отклонили:
- Порог p95 < 1.5s/2s без обоснования; использование N без определения; отсутствие решения по запуску нагрузочных прогонов.
