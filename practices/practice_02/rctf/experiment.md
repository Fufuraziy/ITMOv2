# R.C.T.F. Experiment

- Артефакт-источник: practices/practice_01/tests_load.md — шаблонная таблица, отсутствует решение об отсрочке нагрузочного тестирования, цели p95 не согласованы, нет методики.

## Reasoning

- Требуется согласование SLO (problem.md: p95 ≤ 3s, 5xx ≤ 1%), фиксация N=20000 (CASE.md API-1) и методики (k6 thresholds). Нужен чёткий блок про отсрочку запуска нагрузочного тестирования и условия его старта.

## Critique

- Шаблон «Если нагрузочное тестирование пока не требуется…» не заполнен; пороги p95 (1.5s/2s) не подтверждены problem.md; N не определён; нет методики.

## Test

- Проверки артефакта: присутствуют ли явные N=20000, пороги p95 ≤ 3s и 5xx ≤ 1%, методика k6 с thresholds, и формализовано ли решение об отсрочке с условиями снятия.

## Fix

- Создана корректная версия: practices/practice_02/rctf/tests_load.md — таблица сценариев с явными порогами, методика k6, блок «обоснование отсрочки», раздел об использовании AI.

## Что отклонили

- Порог p95 < 1.5s/2s без обоснования; использование нефиксированного N; отсутствие решения по запуску нагрузочного тестирования.
