# Quickstart: проверка переключателя порций

## Что нужно

- Установленное окружение проекта (`bash scripts/setup.sh` на новой машине).
- Для ручной проверки новых карточек — бэкенд команды 2 с полем `variants` (`specs/002-servings-logic`). Без него проверяется только сценарий выката (карточка без переключателя).

## Автоматическая проверка

```bash
sh scripts/check.sh frontend
```

Ожидание: последняя строка `CHECK PASS`; среди тестов есть сценарии из таблицы ниже.

| сценарий | требования | где |
|---|---|---|
| ×2 меняет итог, состав и ссылку; другие карточки остаются ×1; запросов нет | US1.1–1.3, US2.1, FR-002, FR-003, FR-005 | `App.test.tsx` |
| выбор переживает смену фильтра, когда подборка ушла и вернулась | US1.4, FR-011 | `App.test.tsx` |
| «было» только у масштабируемых товаров | US1.6, FR-004 | `App.test.tsx`, `servings.test.ts` |
| неполные или отсутствующие `variants` → карточка как раньше | US4.3, FR-010 | `servings.test.ts`, `App.test.tsx` |
| `available: false` → сегмент неактивен, `reason` в описании | US4.2, FR-009 | `App.test.tsx` |
| «больше бюджета» у ×N выше бюджета | FR-016 | `App.test.tsx` |
| «Ищем подборки…» до первого ответа | FR-015 | `App.test.tsx` |
| в поиске нет `servings` | FR-018 | `App.test.tsx` |
| `ApiError` содержит `status` и `code` | FR-019 | `api.test.ts` |

Состав и доступные имена — [contracts/ui-card.md](contracts/ui-card.md); данные — [contracts/api-consumed.md](contracts/api-consumed.md).

## Ручная проверка

```bash
bash scripts/dev.sh
```

Открыть `http://localhost:5173`.

1. **Старый бэкенд** (нынешний `main`): карточки без переключателя, всё как раньше.
2. **Бэкенд с `variants`**:
   - в карточке «×1» выбран; нажать «×2» — итог с «· ×2», в составе «было» у масштабируемых товаров; вкладка сети без новых запросов;
   - нажать кнопку корзины — открывается vkusvill.ru, состав корзины совпадает с составом карточки ×2;
   - выбрать бюджет «до 1 000 ₽» и ×4 у подходящей подборки — появляется «больше бюджета»;
   - сменить запрос так, чтобы подборка ушла, и вернуть — выбор ×4 на месте; перезагрузить — ×1;
   - Tab до переключателя, стрелки — выбор меняется, программа чтения с экрана читает «×2, выбрано» и новый итог.
3. **Ширина 360 px**: переключатель отдельной строкой, без горизонтальной прокрутки. Скриншоты 360 px и десктоп — по skill frontend-design.
