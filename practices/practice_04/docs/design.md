# Дизайн страницы (skill frontend-design)

**Предмет и задача.** Готовые продуктовые наборы ВкусВилла под повод. Аудитория — тот, кто решает «что приготовить» и не хочет собирать корзину по одному товару. Главное действие — найти набор под случай и бюджет и перенести его в корзину.

## План

| токен | значение | роль |
|---|---|---|
| `--paper` | `#F3F5EE` | фон: холодная бумага (не тёплый кремовый) |
| `--ink` | `#1B2A21` | текст: тёмная хвоя вместо чёрного |
| `--leaf` | `#2C7A45` | единственный яркий цвет — кнопка «Перенести в корзину ВкусВилла» и набранный запрос |
| `--shelf` | `#D9E0D2` | полки, линии, чипы |
| `--receipt` | `#FFFFFF` | чек и подложка фото |

- **Шрифт:** Onest (кириллический гротеск), одно семейство; заголовки 800 с трекингом −0,035em, цены — табличные цифры.
- **Макет:** герой — сам поиск. Вопрос «Что приготовим?» и поле ввода одного кегля, набранный запрос продолжает заголовок. Подборки — «полки»: слева фото товаров стоят на планке, справа название, описание, теги, итог и кнопка. Выравнивание по левому краю.
- **Принципы:** украшение — только настоящие фото товаров; смелость — в одном месте (строка поиска); цены честные («≈», дата снимка); движение только в ответ на действие (чек «печатается» при открытии), с учётом reduced motion.

## Сверка с шаблонными решениями

Нет кремового фона с терракотой, нет сетки одинаковых карточек с тенью, нет капслок-надзаголовков, мета-строк через «·», моноширинных подписей и «→» в кнопках.

## Самокритика по скриншотам

1. Первый вариант: облако из 21 тега в три строки спорило с поиском → оставлены 10 популярных + «ещё N» (выбранный тег виден всегда).
2. У фото ВкусВилла свой серый фон, в белых плитках были видны полосы → `object-fit: cover`.
3. Мобильная ширина проверена эмуляцией 375 px: горизонтальной прокрутки нет.
