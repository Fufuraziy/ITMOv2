# Фичи сервиса подборок

Сервис помогает **найти** готовый набор продуктов под повод и перенести его в корзину ВкусВилла. Подборки собирает куратор, пользователи их не создают.

## Сделано

| фича | где | как устроено |
|---|---|---|
| Каталог из MCP ВкусВилла | `catalog/themes.json` → `mcp/vv-collections/curate.mjs` → `backend/catalog/collections.json` | куратор описывает тему и поисковые запросы, скрипт выбирает товары через `vkusvill_products_search` и создаёт корзину через `vkusvill_cart_link_create` |
| Проверка каталога при старте | R1, R3 | невалидный каталог не запускается; тест проверяет файл из репозитория |
| Поиск по тексту | R2 `q` | все слова, по названию, описанию, тегам и товарам; регистр и `ё/е` не важны |
| Фильтр по поводу | R2 `tag`, R5 `/tags` | 10 популярных тегов + «ещё N» |
| Бюджет | R2 `max_price` | «до 500 / 1 000 / 2 000 ₽» |
| Сортировка по цене | R2 `sort` | дешевле/дороже/как в каталоге |
| В корзину одной кнопкой | `cart_url` | ссылка `vkusvill.ru/?share_basket=…`: ВкусВилл показывает «С вами поделились товарами» |
| Состав-«чек» | фронтенд | количество, цена за единицу, ссылка на товар |
| Поиск в адресе страницы | фронтенд | `?q=суп&max_price=1000` — ссылкой на выдачу можно поделиться |
| MCP для агента | `search_collections`, `get_collection`, `list_tags` | агент подбирает набор под просьбу пользователя и отдаёт ссылку на корзину |

## Можно добавить

Сначала то, что опирается на уже доступные инструменты MCP ВкусВилла.

| идея | ценность | на чём строится |
|---|---|---|
| **Замена товара аналогом** | нет любимой сметаны — предложить похожую и пересобрать корзину | `vkusvill_product_analogs` + `vkusvill_cart_link_create` на лету |
| **Скидки в подборке** | бейдж «−15% на 2 товара» и сортировка «выгодные» | `vkusvill_products_discount`, поле `price.old` при пересборке каталога |
| **Рецепт к подборке** | шаги приготовления рядом с составом | `vkusvill_recipes` по названию подборки |
| **Порции ×2 / ×4** | масштабировать количество и получить новую корзину | умножить `quantity`, новая ссылка `vkusvill_cart_link_create` |
| **КБЖУ подборки** | фильтр «белковые», «до 600 ккал на порцию» | свойство «Пищевая ценность» из `vkusvill_products_search` (mode full) |
| **Ежедневное обновление цен** | цены и наличие не устаревают; бейдж «подорожало» | запуск `curate.mjs` по расписанию + сравнение с прошлым снимком |
| **Наличие в магазине рядом** | «соберёт ли мой магазин эту подборку» | `vkusvill_shops`; наличие требует OAuth пользователя |
| **Исключить продукт** | `q=сыр -мёд`, аллергии и «без мяса» | R6 в контракте, задание для [демо-сессии](demo-prompt.md) |
| **Избранное и «уже пробовал»** | вернуться к подборке | `localStorage` на фронтенде, без аккаунтов |
| **Сезонные и праздничные подборки** | «Новый год», «Масленица» | теги + даты показа в `themes.json` |
| **Postgres** | хранить снимки каталога и историю цен | реализация `Store` |
