# REPORT

## Оборудование и окружение
- CPU: Intel Core i7‑1165G7 (4C/8T), AVX2/AVX‑512; среда: WSL2 (Windows Subsystem for Linux)
- RAM: 8 ГБ (на момент запуска свободно ~0.7–1.5 ГБ)
- Диск: ~100 ГБ свободно на корневом разделе
- ОС ядро (WSL): Linux 4.4.0-19041-Microsoft
- Ollama: 0.34.4

## Модель
- ID: qwen2.5:1.5b-instruct (через Ollama)
- Квантизация: Q4_K_M (по данным /v1/models)
- Контекст: запрошено 8k (opencode ограничен 8k; базовая Modelfile — 4k для стабильности)

## Обоснование выбора
- В текущей конфигурации WSL доступная память ограничена (<2–3 ГБ свободно), поэтому 3B/7B модели часто OOM и медленные.
- Qwen2.5 1.5B даёт приемлемое качество на русском и быстрый отклик на CPU.
- Квантизация Q4_K_M укладывается в ~1 ГБ веса и ~1.5–2.5 ГБ RAM при инференсе.

## Настройка
- opencode.json на корне указывает провайдера Ollama и модель `ollama/qwen2.5:1.5b-instruct`.
- Создан кастомный тег `itmo-agent` на базе qwen2.5:1.5b-instruct с параметрами num_ctx=8192, temperature=0.2 (локально через API create).
- Внутренние файлы в папке `lab/` не трогались для целей этого отчёта — работу в `lab` поручено выполнять локальной модели отдельно.

## Ограничения и наблюдения
- В WSL GPU недоступна, всё на CPU. Скорость 10–40 ток/с для 1.5B в Q4.
- Возможно некорректное фактическое знание локальных деталей — желательно всегда подавать контекст из файлов.
- Для устойчивости держать свободно ≥2 ГБ RAM или запускать Ollama нативно в Windows.
